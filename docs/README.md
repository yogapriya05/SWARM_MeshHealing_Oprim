# Documentation guide

This folder contains the project explanation, implementation notes, and
reproducible evidence. Start with the short documents below; the longer
formulation document is useful when you need the equations behind the code.

| Document | Use it for |
|---|---|
| [`../README.md`](../README.md) | Install and run the application |
| [`INTEGRATED_V1_README.md`](INTEGRATED_V1_README.md) | Understand the dashboard and the normal mission workflow |
| [`INTEGRATION.md`](INTEGRATION.md) | See which module owns each behaviour |
| [`FORMULATION.md`](FORMULATION.md) | Read the mathematical model and its limitations |
| [`BREAK_EVEN.md`](BREAK_EVEN.md) | Generate and interpret the operational viability figure |
| [`LITERATURE.md`](LITERATURE.md) | See how external sources were used |

The PDF files are background references, not executable specifications. The
application is a simulator, so its thresholds and resource values should be
read as controlled experiment settings rather than flight qualification limits.
